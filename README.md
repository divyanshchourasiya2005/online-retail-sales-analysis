# Online Retail Sales Analysis

> Data Analytics Portfolio Project using Python

## Overview

This project analyzes **541,909 online retail transactions** to uncover customer purchasing behavior, revenue trends, and product performance.

The analysis demonstrates data cleaning, exploratory data analysis (EDA), and business insight generation using Python.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## Dataset

- UCI Online Retail Dataset
- 541,909 transactions
- Multiple countries
- Real-world retail sales data

## Project Workflow

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis
4. Business Insights
5. Data Visualization

## Key Business Insights

- Holiday months generated the highest revenue.
- The United Kingdom contributed the largest share of sales.
- Afternoon hours recorded peak order activity.
- A small percentage of customers generated a large portion of revenue.
- Gift and decorative products were top performers.
- Most purchases involved low-priced products.
- Q4 showed strong seasonal growth.
- Repeat customers significantly boosted revenue.
